# GuardFlow β — 警備業務クラウド デモ

警備業向け業務管理システムのUIプロトタイプ。**隊員向けスマホアプリ**と**管制センター向けPC画面**の2面構成を、ビルド不要の静的Webアプリ（HTML / CSS / Vanilla JS）で実装しています。

👉 **[デモを開く](https://playmark0227-svg.github.io/guardflow-demo/)** ／ 📘 **[画面説明資料（全24画面）](https://playmark0227-svg.github.io/guardflow-demo/docs/)**

> これは実データを持たないUI検証用のプロトタイプです。表示される会社名・隊員名・現場名・金額はすべて架空のサンプルデータで、ブラウザの localStorage にのみ保存されます。サーバー送信は一切ありません。

---

## 2つの画面

画面上部の「📱 隊員アプリ / 🖥️ 管制センター」で切り替えます。

### 📱 隊員アプリ

現場の隊員がスマホで使う想定。下部5タブ構成。

| タブ | 内容 |
|---|---|
| お知らせ | 本社からの一斉連絡、バージョン告知 |
| 勤怠報告 | 出発 / 合流 / 上番 / 下番 / 休憩開始 / 休憩終了 をラジオ選択 → GPS付きで報告 |
| シフト管理 | 予定一覧 → 詳細（得意先・配置先・住所・同配置者・備考／地図・トイレ・コンビニ検索） |
| 休暇申請 | 月カレンダーから申請。申請済 / 交渉可 / 承認済み / 棄却 を色分け表示 |
| 給与管理 | 支給・控除の明細表、PDF出力 |

### 🖥️ 管制センター

管制・事務が使う想定。左サイドバー＋トップバー構成。

- **ダッシュボード** — 勤務予定の入力漏れ、勤務実績のチェック漏れ、売上推移グラフ（前年比）、優先タスク一覧
- **勤務管理（管制ボード）** — 現場カードへのドラッグ&ドロップ配置、人員充足状況
- **上下番モニター** — 出発→上番→下番の進行状況、GPS位置、未出発アラート
- **請求 / 入金 / 給与管理** — 現場別請求額、入金消込、隊員別給与一覧
- **帳票管理** — 警備員名簿・配置予定表のPDF出力
- **マスタ管理 / 有休管理 / 教育管理 / 収支分析**

## 実装した特徴

現場業務でつまずきやすい点を意識的に潰しています。

- **日跨ぎ夜勤に対応** — 0:00開始の勤務でも前夜から出発報告ができる（日付をまたいでもエラーにならない）
- **オフライン打刻キュー** — 圏外でも端末に保存し、通信回復時に自動同期（ヘッダーの「📡 圏外」トグルで体験可能）
- **GPS自動添付** — 打刻時の位置情報を記録し、管制側の地図リンクから確認
- **給与明細のPDF出力** — 閲覧だけでなく印刷・保存が可能
- **配置バリデーション** — ダブルブッキング / 出入り禁止 / 隊員同士の相性NG を自動ブロック、注意喚起は警告付きで配置続行
- **法定教育の進捗管理** — 新任20h・現任10hの達成状況と未達アラート
- **ダークモード対応** — 右上のボタンで切替

## ローカルで動かす

ES Modules を使っているため `file://` では動きません。簡易サーバーを立ててください。

```bash
python3 -m http.server 8931 --directory app
```

http://localhost:8931 を開きます。

## 構成

```
app/
  index.html
  css/style.css
  js/
    app.js      エントリポイント、イベント委譲、テーマ、印刷
    store.js    状態管理と localStorage 永続化
    data.js     デモ用シードデータ（今日を基準に日付を生成）
    guard.js    隊員アプリの各画面
    admin.js    管制センターの各画面
    prints.js   給与明細・請求書・名簿などの帳票HTML
    util.js     日付・時刻・金額のユーティリティ
```

依存パッケージなし。ビルド不要。`main` ブランチへの push で GitHub Actions が `app/` を GitHub Pages へ配信します。
